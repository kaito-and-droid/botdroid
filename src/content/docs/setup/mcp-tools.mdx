**MCP** servers give an AI agent tools: live prices, search, blockchain data and more. The agent calls them when it needs real data for an answer.

<Aside type="caution">An MCP server receives the questions the agent sends it. Only add servers you trust.</Aside>

## How to

<Tabs>
	<TabItem label="Sign in to a server" icon="padlock">
		<Steps>
		1. Open the bot → **Tools** tab.
		2. Edit the server, for example `binance`.
		3. Tap **Connect**. The sign-in page opens inside the app.
		4. Sign in and approve.
		</Steps>
	</TabItem>
	<TabItem label="Add your own server" icon="add-document">
		<Steps>
		1. Open an AI agent bot → **Tools** tab → **Add server**.
		2. Enter a name and the server URL (HTTP or SSE).
		3. If it needs OAuth, tap **Connect**.
		4. If the bot was running, restart it to load the new tools.
		</Steps>
	</TabItem>
</Tabs>
