Máy chủ **MCP** cung cấp công cụ cho agent AI: giá trực tiếp, tìm kiếm, dữ liệu blockchain và hơn thế. Agent gọi chúng khi cần dữ liệu thật để trả lời.

<Aside type="caution">Máy chủ MCP nhận các câu hỏi agent gửi tới. Chỉ thêm máy chủ bạn tin tưởng.</Aside>

## Cách làm

<Tabs>
	<TabItem label="Đăng nhập máy chủ" icon="padlock">
		<Steps>
		1. Mở bot → tab **Tools**.
		2. Sửa máy chủ, ví dụ `gondola`.
		3. Nhấn **Connect**. Trang đăng nhập mở ngay trong app.
		4. Đăng nhập và chấp thuận.
		</Steps>
	</TabItem>
	<TabItem label="Thêm máy chủ của bạn" icon="add-document">
		<Steps>
		1. Mở một bot agent AI → tab **Tools** → **Add server**.
		2. Nhập tên và URL máy chủ (HTTP hoặc SSE).
		3. Nếu cần OAuth, nhấn **Connect**.
		4. Nếu bot đang chạy, khởi động lại để nhận công cụ mới.
		</Steps>
	</TabItem>
</Tabs>
