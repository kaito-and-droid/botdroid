// THE PROBLEM

Running a Telegram or AI bot shouldn't require a server.

A side-project bot that handles 30 messages a day doesn't deserve a $5–15/mo VPS, an SSH key, a Linux distro to update, and a process to babysit.

VPS BILL

$60–180/year for compute that's idle 99% of the time. You're paying for the privilege of restarting `systemd` after every kernel update.

SETUP HELL

SSH, firewall, Python, virtualenv, systemd unit, log rotation, secret management, TLS, reverse proxy — before a single message gets answered.

BABYSITTING

Process crashed at 3am. Disk full. CVE in your distro. You woke up to 200 unanswered DMs and an angry user.

// THE SOLUTION

Your Android phone is a server you're already paying for.

BotDroid runs every bot as a foreground OS process with a WakeLock — the same primitive that keeps your music app alive. Survives screen-off, app-swiped, and OEM battery killers. Restarts itself on crash. Comes back after reboot.

  • FOREGROUND SERVICE + WAKELOCK
  • EXPONENTIAL-BACKOFF RESTART
  • BOOT RESTORE ON DEVICE REBOOT
  • DAILY SCHEDULED START/STOP
  • ENCRYPTED LOCAL STORAGE
  • RECOVERS CLEANLY AFTER FORCE-CLOSE

// FEATURES

Everything a bot needs. Nothing it doesn't.

Built for the indie dev who'd rather ship a bot than learn another DevOps tool.

01 · TWO BOT TYPES

PicoClaw agent + Python script

A bundled AI agent runtime (picoclaw) ships in the APK. Or paste raw Python and import from any GitHub URL — BotDroid downloads CPython 3.15 ARM64 once and SHA-256–verifies it.

02 · BRING YOUR OWN KEY

6 LLM providers, validated

OpenRouter, OpenAI, NVIDIA, Gemini, Groq, Cloudflare Workers AI built in — or any OpenAI-compatible endpoint (DeepSeek, xAI, …) via Custom, plus Anthropic Claude through OpenRouter. The Add-Bot flow pings your key before saving — no silent misconfig.

03 · MULTI-CHANNEL

8 chat channels, one tap

Telegram, Discord, Slack, Zalo, LINE, DingTalk, Feishu/Lark, WeCom. Telegram and Zalo are the verified first-class paths and persist a 40-message rolling memory window per chat to Room; the rest run via the picoclaw gateway and carry a BETA badge.

04 · 24/7 PERSISTENCE

Survives screen-off, crash, reboot

Foreground service + WakeLock + START_STICKY. Exponential-backoff restart on crash, capped at 120 s. AlarmManager keeps daily schedules; boot receiver restores them.

05 · OPERATIONAL DASHBOARD

Per-provider spend, in real time

Sessions, requests, input/output tokens, throughput, estimated cost — aggregated per bot and per provider. Crashlytics on every lifecycle event.

06 · LOCAL-FIRST SECURITY

AES-256-GCM, Android Keystore

Every secret lives in EncryptedSharedPreferences, keyed per bot. Wiped atomically on delete. Logs and metrics stay on-device — only your LLM calls leave the phone.

// FAQ

Common questions.

What does the free tier include?

One bot, free forever — all 6 built-in LLM providers (plus any OpenAI-compatible endpoint), all 8 channels, 24/7 persistence, daily start/stop schedule, logs, and the spend dashboard. Pro ($4.99/mo, or $19.99 once for lifetime) removes the bot limit and adds scheduled agent tasks.

Is there a free trial or promo code?

The free tier is genuinely free forever (1 bot) — no trial clock on it. Separately, at launch we'll run promo codes that unlock a 30-day full-Pro trial: open Settings, enter your email or the promo code you were given, and unlimited bots + scheduled tasks unlock for the month. No card, cancel-nothing — it simply reverts to Free when the 30 days are up.

What is the bot template marketplace?

A planned curated store of pre-built bot templates inside the app: a ready-to-run script, setup instructions, and recommended LLM config, deployed in one tap. It's not in the current beta yet — creators will earn 70% of each sale when it ships.

Will my bot really run 24/7 on a phone?

Yes — provided you grant the battery-optimization exemption. BotDroid uses Android's foreground-service primitive (same one music players use) plus a partial WakeLock. We tested on aggressive OEMs (Samsung One UI, Xiaomi MIUI). Some manufacturers add extra restrictions on top of stock Android; the in-app Settings screen walks you through them.

Where are my tokens and API keys stored?

In EncryptedSharedPreferences backed by AES-256-GCM keys in the Android Keystore. Per-bot, atomic delete. Never logged, never sent to any BotDroid server — we don't run servers. Outbound traffic only goes from your phone to the LLM provider you configured.

Do I have to know Python to use this?

No. For an AI bot, pick "PicoClaw agent," drop in a Telegram token + LLM key, and you're done. Python is only needed if you want full control over the bot's behavior — and even then, paste a script (or import one from a GitHub URL) and BotDroid handles the rest.

Which devices are supported?

Android 10+ (API 29), ARM64. That's any phone made since ~2019. ARM32 and x86 are not currently supported.

Can I install it without Google Play?

Yes. Besides Google Play, BotDroid is also distributed as a direct-download APK for anyone who can't use the Play Store. On the direct build, Pro is a one-time $19.99 lifetime license key (same app, same features), and the app checks for its own updates. The download link goes live alongside the public release.

Does BotDroid charge for LLM usage?

No. You bring your own provider key (OpenRouter, OpenAI, Groq, or any OpenAI-compatible endpoint) and your provider bills you directly. BotDroid's in-app dashboard estimates spend so you can see it in one place — we never sit between you and your LLM.

Can my bot run fully offline, without any API key?

Coming soon. We're testing an on-device model option (currently internal builds only) that runs a small local LLM directly on your phone — zero API key, zero LLM cost, works with no internet connection. It's not in the public build yet; follow r/BotDroid for when it ships.

What happens to my bots when I reboot the phone?

A boot receiver re-starts every bot that was running, and restores active daily schedules. Crash counts and uptime tickers reset; conversation memory (Telegram + Zalo) persists across reboots via Room.

Is the source code available?

The app is closed-source today. The embedded AI agent runtime (picoclaw) is open source and bundled via its own MIT-licensed binary.

How do I get support or report a bug?

Email kaiteam@proton.me — that's a real inbox we read, not a ticket queue. For quicker back-and-forth, or to see what other users are hitting, post in r/BotDroid. If a specific bot is misbehaving, grab its live logs (bot detail → Logs) before you write in — it makes diagnosis much faster.
